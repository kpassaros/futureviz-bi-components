DataStudio

Instalar o Templr como Community Visualization

1

Abra a galeria de visualizações e componentes da comunidade.

2

Acesse as visualizações criadas por desenvolvedores.

3

Informe o caminho do manifesto gs://templr.

4

Autorize, adicione o componente e posicione-o no canvas.

5

Configure dimensões, métricas e propriedades do relatório.

6

Use Template para HTML, Style para CSS e Experimental para JavaScript.

Atenção: JavaScript é experimental. Eventos DOM e scripts podem ser bloqueados. Sempre valide filtros, segurança e responsividade.
