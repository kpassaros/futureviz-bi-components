# Componentes FutureViz

## Paridade entre plataformas

As três coleções usam as mesmas 12 famílias visuais:

1. Receita total;
2. Progresso da meta;
3. Comparativo de períodos;
4. Fluxo de caixa;
5. Status operacional;
6. Grid multi-KPI;
7. Análise de tendências;
8. Ranking compacto;
9. Funil de conversão;
10. Tickets e SLA;
11. Saúde do estoque;
12. Sprint em andamento.

## DataStudio

Cada pasta contém `template.html`, `style.css` e `README.md` com campos/dados mínimos. O campo Experimental permanece vazio.

A coleção foi expandida a partir dos padrões aprovados de métricas, dimensões, datas, repetição, condicionais, cálculos, formatação e Top N.

## Power BI

Os componentes usam medidas DAX e HTML Content.

## WebDev

Cada pasta contém `index.html`, `style.css`, `script.js` e `README.md`. Os componentes não exigem dependências externas e expõem um método global `render`.
