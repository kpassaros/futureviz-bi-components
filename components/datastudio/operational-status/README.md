# Status operacional — DataStudio

Lista indicadores e calcula automaticamente o atingimento.

## Campos
- 1 dimensão: indicador, serviço, processo ou categoria.
- 1 métrica: valor atual.
- 1 métrica: referência ou meta.

## Estados
- Saudável: 100% ou mais.
- Atenção: 80% a 99,99%.
- Crítico: abaixo de 80%.

A lógica deste componente é `quanto maior, melhor`. Decimais usam no máximo 2 casas. Mantenha Experimental vazio.
