# Concentração de fluxo — Power BI

Use uma matriz/tabela nativa ou visual HTML compatível em conjunto com:

- parâmetro de campo para alternar Entidade, Categoria e Faixa de atraso;
- medida de saída realizada;
- filtro Top N do Power BI;
- formatação condicional baseada em uma única paleta.

A versão HTML completa será amadurecida na v1.1. O MVP documenta o contrato e mantém equivalência conceitual com o componente DataStudio.
