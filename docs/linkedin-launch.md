## 1 — Projeto FutureViz Components

Hoje estou apresentando a primeira versão da **FutureViz Components**: uma biblioteca aberta de componentes UI configuráveis para Power BI e DataStudio.

O projeto nasceu de um problema recorrente: dashboards precisam ir além dos componentes nativos, mas uma melhoria visual só faz sentido quando preserva métricas, agregações, filtros, responsividade e clareza.

Em vez de produzir várias cópias rígidas do mesmo layout, construí uma abordagem orientada por metadados. Dimensão, métrica, formato, cores e plataforma podem redefinir o componente e o código gerado.

Na primeira bateria do DataStudio foram 20 testes validados, incluindo filtros combinados, formatação, regras condicionais, estados vazios, Top N, tooltip, cross-filter recebido e um teste com 2.508 registros filtrados sem travamento perceptível.

A v1 também apresenta duas frentes:

• Central de Coleções — componentes prontos para configurar e copiar.  
• FutureViz Lab — prévia, propriedades e código em uma única experiência.

Este é o começo. Cards, concentração de fluxo, progresso de meta e grid multi-KPI abrem caminho para tabelas, funis, tendências e novos adaptadores.

## 2 — Atualização do portfólio

Atualizei meu portfólio de Dados e BI com uma direção mais objetiva: menos projetos genéricos e mais cases práticos, interativos e documentados.

O CashFlow permanece como o principal case, reunindo tratamento com Apps Script, cálculos e validações no DataStudio, documentação técnica e um dashboard interativo.

A nova atualização também incorpora a **FutureViz Components**, projeto em que estou construindo componentes UI configuráveis para Power BI e DataStudio. A proposta é transformar problemas encontrados em dashboards reais em soluções reutilizáveis, com código aberto, documentação e critérios claros de validação.
