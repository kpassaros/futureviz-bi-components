Power BIDataStudioWebDev

Power BI + HTML Content

  1. Instale o visual HTML Content.
  2. Crie as medidas exigidas.
  3. Copie a DAX completa.
  4. Substitua somente os bindings entre colchetes.
  5. Adicione a medida ao visual.
  6. Valide filtros, nulos e publicação.

DataStudio + Templr

  1. Abra as visualizações da comunidade.
  2. Acesse as visualizações de desenvolvedores.
  3. Informe gs://templr.
  4. Configure dimensões, métricas e ordenação.
  5. Cole o HTML em Template.
  6. Cole o CSS em Style.
  7. Deixe Experimental vazio nos componentes DataStudio desta versão.

Os oito componentes atuais não utilizam JavaScript Helpers. Copie sempre os códigos completos de Template e Style.
