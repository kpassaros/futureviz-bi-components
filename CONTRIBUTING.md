# Contribuindo

1. Abra uma issue descrevendo o problema de BI atendido.
2. Declare plataforma, dimensões, métricas, formatos e limitações.
3. Inclua dados fictícios reproduzíveis.
4. Adicione Template/Style ou DAX e uma prévia.
5. Valide filtros, zero, nulos, negativos, responsividade e contraste.
6. Não copie bundles ou ativos sem licença compatível.

## Checklist de componente

- [ ] Nome orientado ao problema, sem promessas enganosas.
- [ ] Contrato de dados documentado.
- [ ] Nomes de campos dinâmicos quando suportado.
- [ ] Formatos configuráveis.
- [ ] Estado sem dados.
- [ ] Tema claro e escuro.
- [ ] Teste com filtros.
- [ ] Limitações registradas.
- [ ] Código formatado e sem dependências ocultas.
